---
title: "Commands"
description: "Reference for the bellucode command line."
---

Every command accepts `--help` for its full flag list, for example `bellucode run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ bellucode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Bellu Code review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @bellucode/cli
      - run: bellucode run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ bellucode run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ bellucode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ bellucode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ bellucode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ bellucode run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ bellucode run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ bellucode run --auto "Fix the failing test"
```

Create the session archived so scripted or CI runs stay out of session lists and the inbox. The session still exists: `bellucode session list` includes it, and you can open it by ID.

```bash
$ bellucode run --archived "Review this diff"
```

View all subcommands and flags.

```bash
$ bellucode run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ bellucode mini
```

Continue the last session.

```bash
$ bellucode mini --continue
```

Start with a model and an initial prompt.

```bash
$ bellucode mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ bellucode mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ bellucode mini --help
```

## session

Manages sessions.

```bash
$ bellucode session list
```

Limit the list and print JSON.

```bash
$ bellucode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ bellucode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ bellucode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ bellucode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ bellucode session import session.json
```

Import into a specific directory.

```bash
$ bellucode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ bellucode session --help
```

## auth

Manages AI providers and credentials.

```bash
$ bellucode auth list
```

List them as JSON.

```bash
$ bellucode auth list --format json
```

Log in to a provider.

```bash
$ bellucode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ bellucode auth login anthropic --method key
```

Log out of a saved account.

```bash
$ bellucode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ bellucode auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ bellucode auth export anthropic > credentials.json
$ bellucode auth import credentials.json
```

View all subcommands and flags.

```bash
$ bellucode auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ bellucode mcp list
```

Add a remote server.

```bash
$ bellucode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ bellucode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ bellucode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ bellucode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ bellucode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ bellucode mcp logout sentry
```

View all subcommands and flags.

```bash
$ bellucode mcp --help
```

## plugin

Manages plugins.

```bash
$ bellucode plugin list
```

Include built-in server plugins.

```bash
$ bellucode plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ bellucode plugin add @example/bellucode-tui
```

Check package plugins for updates.

```bash
$ bellucode plugin check
```

Update package plugins.

```bash
$ bellucode plugin update
```

Remove a plugin from global configuration.

```bash
$ bellucode plugin remove @example/bellucode-tui
```

View all subcommands and flags.

```bash
$ bellucode plugin --help
```

## stats

Shows shareable usage statistics.

```bash

```

Show the last 7 days.

```bash
$ bellucode stats --days 7
```

Show model usage.

```bash
$ bellucode stats --models
```

Show cost and token details.

```bash
$ bellucode stats --cost
```

Print JSON instead of a report.

```bash
$ bellucode stats --json
```

Show only the current project.

```bash
$ bellucode stats --project .
```

View all subcommands and flags.

```bash
$ bellucode stats --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ bellucode serve
```

Bind to all interfaces on a fixed port.

```bash
$ bellucode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ bellucode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ bellucode serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ bellucode pair
```

Use an external URL in the links.

```bash
$ bellucode pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ bellucode pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ bellucode pair --remote --yes
```

View all subcommands and flags.

```bash
$ bellucode pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ bellucode service start
```

Restart it.

```bash
$ bellucode service restart
```

Show its status.

```bash
$ bellucode service status
```

Stop it.

```bash
$ bellucode service stop
```

Read a setting.

```bash
$ bellucode service get hostname
```

Set a setting.

```bash
$ bellucode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ bellucode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ bellucode service set env BELLUCODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ bellucode service unset hostname
```

View all subcommands and flags.

```bash
$ bellucode service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ bellucode reload
```

## api

Makes a request to the running server.

```bash
$ bellucode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ bellucode api session.list --param limit=10
```

Send a JSON body.

```bash
$ bellucode api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ bellucode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ bellucode api --help
```

```bash
$ bellucode acp
```

View all subcommands and flags.

```bash
$ bellucode acp --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ bellucode debug agents
```

List configuration sources.

```bash
$ bellucode debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ bellucode debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ bellucode debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ bellucode debug paths
```

Print a single path.

```bash
$ bellucode debug paths db
```

View all subcommands and flags.

```bash
$ bellucode debug --help
```

## upgrade

Upgrades Bellu Code to the latest or a specific version. Alias: `update`.

```bash
$ bellucode upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ bellucode upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ bellucode upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls BelluCode. Session data, configuration, and
state are not removed.

```bash
$ bellucode uninstall
```

Preview what would be removed.

```bash
$ bellucode uninstall --dry-run
```

View all subcommands and flags.

```bash
$ bellucode uninstall --help
```
